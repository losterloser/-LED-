# 可复用技能包

本目录满足提交要求 3.3.5.2。它将工程中的复现、时序校验和上板排错经验提炼为一个可复制技能，不依赖本人的磁盘路径、歌曲或账号。

| 项目 | 适用范围 | 使用方法 | 失效条件 |
| --- | --- | --- | --- |
| [fpga-audio-reproduce](fpga-audio-reproduce/README.md) | Vivado RTL 流式音频工程及电脑协助的结果回传 | 读取该目录的 SKILL.md，选择复现、报告校验或上板排错流程 | 器件、时钟、外设协议不同却仍沿用本工程约束时，不可直接上板 |
| 提示词工作流 | 把新算法需求拆成 RTL、主机处理和验收证据 | 使用 references/prompts.md 并替换板型、接口与目标指标 | 缺少规格或没有实测输入时，不能替用户确认硬件通过 |
| 报告校验脚本 | Vivado setup/hold、资源预算、未约束端点与总线偏斜 | 复制 build/check_reports.py，配合自己的 JSON 配置运行 | 报告表格格式改变或关键表格缺失会报错，不自动视为通过 |
| 验收模板与踩坑清单 | 分离仿真、日志、用户观察和完整验收 | 使用 assets/acceptance-template.json 与 references/pitfalls.md | 没有原始证据时只能保留待测，不把历史通过当成本轮通过 |

效果依据：本工程的报告校验、33 项主机回归、连续窗口跟踪试验以及真实 JTAG/串口排错；具体边界在技能 README 中说明。该技能没有使用 PYNQ，也不声称符合通用 PYNQ Skill 加分项。
