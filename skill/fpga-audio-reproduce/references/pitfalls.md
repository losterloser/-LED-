# 实际观察整理的排错清单

| 触发条件 | 定位步骤 | 判断边界 |
| --- | --- | --- |
| 下载器可见，但 No devices detected | 核对板端 JTAG、供电与排线；重新注册连接后再次探测；读到预期器件后再下载 | USB 设备存在不等于 JTAG 芯片链有效 |
| 上电后功能与之前不同 | 核对 DONE、CRC、USR_ACCESS；确认是易失 JTAG 配置还是其他启动镜像 | 下载成功不等于写入 Flash |
| 调试核生成因路径长度失败 | 从工程根目录临时映射空闲盘符，用同一份脚本创建与构建；结束仅移除本次映射 | 不删除原工程，不占用已有映射 |
| 屏幕正确但灯环异常 | 核对数据引脚是否被屏幕占用；确认转换器、供电、共地和 DIN；先逐灯再音乐 | 本项目旧 J3-33 已用于 LCD，灯环为 U4-1/N15；其他板不得照抄 |
| 串口已连接但没有有效采样 | 查看当前模式、序号、采样位置、CRC 和丢失增量；排除其他程序占用端口 | 模式切换产生的计数与稳定播放段分开统计 |
| 歌名识别后反复消失 | 保留候选、偏移、特征数与 sample_end，核对同曲偏移是否随新采样推进 | 弱证据可维持已确认身份的前提不等于可取得新身份 |
| 静音后旧歌名重新出现 | 核对持续低电平判断、采样窗刷新、状态复位与迟到结果隔离 | 仅清空界面字符串不等于清空旧音频 |
| 日志显示结果但实物未知 | 同时核对 ACK 与现场观察，记录观察者确认的是哪一项 | ACK 不证明中文、颜色、接线或灯环发光正确 |
| 工程可以运行但陌生电脑无法复现 | 排除绝对路径、缺失生成脚本、未说明的曲库和工具版本；在新目录运行 | 历史二进制可启动不等于新源码构建已复现 |
| Windows 恢复曲库时出现文件占用 | 显式关闭 SQLite 连接后再移动临时数据库；用错误摘要和已有目标的反例验证 | `with sqlite3.connect(...)` 管理事务，不保证关闭连接；不能覆盖用户已有曲库 |
