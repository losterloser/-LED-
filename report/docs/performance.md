# 综合实现与关键指标

原始综合、实现、时钟与检查报告位于 `build/reports/`，工具为 Vivado 2022.2，器件为 xc7z010clg400-1。随包 bit 对应的 54 个 RTL、仿真、约束和数据输入摘要保存在 `build/compiled_inputs.json`。本次主机逻辑修订不改变该 FPGA 输入集合；独立目录的重建记录与原始实现报告分开保存。

| 资源 | 使用量 | 器件总量 | 占比 |
| --- | ---: | ---: | ---: |
| Slice LUTs | 7232 | 17600 | 41.09% |
| Slice Registers | 10560 | 35200 | 30.00% |
| Block RAM Tile | 23 | 60 | 38.33% |
| DSPs | 7 | 80 | 8.75% |

上述资源包含 ILA、识曲降采样、串口与双缓冲中文位图。不能把不同调试配置的结果当作同一实现直接比较。

| 时序项目 | 报告结果 | 解读 |
| --- | ---: | --- |
| Setup WNS | +0.379 ns | 已有约束下最差建立时间裕量非负 |
| Hold WHS | +0.025 ns | 最差保持时间裕量非负 |
| 最小 bus skew 裕量 | +19.145 ns | 随包总线偏斜检查通过 |
| 无时钟寄存器端点 | 0 | 对应 check_timing 原始报告 |
| 未约束内部端点 | 0 | 不等于所有外设 I/O 均已现场标定 |

主时钟按 50 MHz 约束；未把正 WNS 换算成实测最高工作频率。原始 DRC、CDC 及外部 I/O 检查保留，未宣称警告为零。DRC 有 DPIP-1、DPOP-1、DPOP-2、PDCN-1569、RTSTAT-10、ZPS7-1 等警告；原始实现没有 ERROR 或 CRITICAL WARNING。
